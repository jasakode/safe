GO PACKAGE

BIP-0039

A lightweight and idiomatic Go implementation of BIP-0039 mnemonic code for generating deterministic wallet seeds.

Go MIT BIP-0039

Quick Start

Generate a mnemonic and derive a seed using the package.

Go 
package main

import (
    "fmt"

    bip39 "github.com/antoniussinaga/bip-0039"
)

func main() {
    mnemonic, err := bip39.NewMnemonic(128)
    if err != nil {
        panic(err)
    }

    fmt.Println(mnemonic)
}

Mnemonic

BIP-0039 represents entropy as a sequence of human-readable words. The resulting mnemonic can later be converted into a deterministic seed.

i
Security

Never expose or store a production mnemonic in source code, logs, or public repositories.

Seed

A mnemonic can be converted into a deterministic seed using an optional passphrase.

Wordlist

The package supports BIP-0039 wordlists used to encode mnemonic entropy.
